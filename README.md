🐂 Bulls and Cows

A simple number-guessing game built for fun using HTML, CSS, and JavaScript.

The game generates a random 4-digit number with unique digits, and the player tries to guess it. Each guess provides feedback:

Bull → Correct digit in the correct position.
Cow → Correct digit but in the wrong position.

Built as a small practice project to improve my JavaScript fundamentals, DOM manipulation, event handling, and basic game logic.
